# ST-WebAgentBench

Material from ST-WebAgentBench (Levy et al., arXiv 2410.06703, Oct 2024; ICLR 2026): 375 enterprise web tasks (GitLab
and Shopping Admin from WebArena, and SuiteCRM) with 3,057 policy instances in six safety dimensions, scored on two
axes, task success and policy compliance (CuP: completion under policy). Candidate base benchmark for the
rules-in-the-wild study: policies as rules, with and without enforcement (A/B/C), compliance and task success measured
on the same runs.
