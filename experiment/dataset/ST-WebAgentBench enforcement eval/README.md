# ST-WebAgentBench

ST-WebAgentBench (Levy et al., arXiv 2410.06703, Oct 2024; ICLR 2026): 375 enterprise web tasks (GitLab and Shopping
Admin from WebArena, and SuiteCRM) with 3,057 policy instances in six safety dimensions, scored on two axes, task
success and policy compliance (CuP: completion under policy). A candidate benchmark for this study: policies as rules,
with and without enforcement, compliance and task success measured on the same runs. Not used yet.

To use it: clone [segev-shlomov/ST-WebAgentBench](https://github.com/segev-shlomov/ST-WebAgentBench) at commit
`67f56dd` into `ST-WebAgentBench/`. License: Apache-2.0 (the repository's `LICENSE`).
