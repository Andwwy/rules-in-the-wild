# Tests › Runners › pytest
enforcer · The Python test runner.

- install: `pytest` (the project's own packages: `/opt/enforce/tool-installs/pytest/bin/pip install …`)
- check: `pytest -q -x -p no:cacheprovider <project>` (exit 1 when a test fails; 5 when none is found)

Docs: https://docs.pytest.org/
