# Commands › Git
enforcer · The git program: checks on a repository, for example `git diff --check` (whitespace errors) or `git log` (commit
messages).

- install: `git`
- check: `git -C <repository> diff --check`, `git log`, `git status --porcelain`; or a check on git commands before they run

- docs: https://git-scm.com/docs
