# Analysis › Web › Stylelint
enforcer · The linter for CSS, SCSS and Less: rules on properties, values, selectors, names and order.

- install: `stylelint`
- check: `stylelint --config <.stylelintrc.json> <file>`, or the text on stdin with `--stdin-filename <path>`
- config: `{"rules": {"<rule>": <value>}}`

Docs: https://stylelint.io/
