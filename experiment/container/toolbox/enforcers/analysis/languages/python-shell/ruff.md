# Analysis › Languages › Python / shell › Ruff
enforcer · A fast Python linter and formatter: the pycodestyle, pyflakes, isort and pep8-naming rules, and many more.

- install: `ruff`
- check: `ruff check --no-cache --select <codes> <file>`, or the text on stdin: `--stdin-filename <path> -`; formatting: `ruff format --check <file>`

Docs: https://docs.astral.sh/ruff/
