# Analysis › Text › remark-lint
enforcer · A Markdown linter built on remark: each rule is a plugin, and presets group rules.

- install: `remark-lint`
- check: `remark --frail --quiet --no-stdout --no-config --use /opt/enforce/tool-installs/remark-lint/node_modules/<plugin or preset>/index.js <file>` (name each plugin by its path: by name it is not found)

Docs: https://github.com/remarkjs/remark-lint
